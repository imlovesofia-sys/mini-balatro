# Plano: Rebalanceamento de Dificuldade — 8 Antes

## Objetivo
Substituir o sistema atual (6 blinds fixos) por 8 antes com targets calculados dinamicamente.

## Fórmula por Ante
| Ante | Base | Small (×1) | Big (×1.5) | Boss (×2) |
|------|------|------------|------------|-----------|
| 1 | 300 | 300 | 450 | 600 |
| 2 | 800 | 800 | 1.200 | 1.600 |
| 3 | 2.000 | 2.000 | 3.000 | 4.000 |
| 4 | 5.000 | 5.000 | 7.500 | 10.000 |
| 5 | 11.000 | 11.000 | 16.500 | 22.000 |
| 6 | 20.000 | 20.000 | 30.000 | 40.000 |
| 7 | 35.000 | 35.000 | 52.500 | 70.000 |
| 8 | 50.000 | 50.000 | 75.000 | 100.000 |

Total: 24 blinds (8 × 3)

## Arquivos a modificar

### 1. `public/js/constants.js`
- Substituir array `BLINDS` por constante `ANTE_BASES` e função `generateBlinds()`:

```js
export const ANTE_BASES = [300, 800, 2000, 5000, 11000, 20000, 35000, 50000];

export function generateBlinds() {
  const blinds = [];
  ANTE_BASES.forEach((base, ante) => {
    const n = ante + 1;
    blinds.push({ id: `ante${n}-small`, name: `Ante ${n} — Blind Pequeno`, target: base, boss: false, ante: n });
    blinds.push({ id: `ante${n}-big`, name: `Ante ${n} — Blind Grande`, target: Math.floor(base * 1.5), boss: false, ante: n });
    blinds.push({ id: `ante${n}-boss`, name: `Ante ${n} — Blind do Chefe`, target: base * 2, boss: true, ante: n });
  });
  return blinds;
}
```

- Manter `BLINDS` como exportação gerada:
```js
export const BLINDS = generateBlinds();
```

### 2. `public/js/game.js`
- Nenhuma mudança necessária — `BLINDS` já é usado como array indexado por `currentBlindIndex`. A nova array tem 24 itens, o código funciona igual.

### 3. `public/index.html`
- Atualizar texto "Como Jogar" na linha 28:
  - De: `Sobreviva 6 blinds (2 rodadas de 3, sendo a 3ª sempre um Chefe)`
  - Para: `Sobreviva 8 rodadas (Small Blind, Big Blind e Chefe em cada uma)`
